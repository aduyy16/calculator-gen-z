# Good Mood Calculator

> Kalkulator web sederhana dengan tampilan cerah dan palet warna yang bisa diganti. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework atau dependensi build.

## Fitur

- Operasi penjumlahan, pengurangan, perkalian, pembagian, dan persen.
- Mengikuti prioritas operasi matematika.
- Pratinjau hasil saat ekspresi diketik.
- Riwayat hingga enam perhitungan terakhir, disimpan di browser.
- Tiga palet warna: Pop, Peach, dan Lilac.
- Bisa digunakan dengan tombol kalkulator atau keyboard.
- Layout responsif untuk desktop dan ponsel.

## Menjalankan Secara Lokal

1. Clone repositori ini:

   ```bash
   git clone https://github.com/aduyy16/calculator-gen-z.git
   cd calculator-gen-z
   ```

2. Buka `index.html` di browser.

Tidak perlu instalasi package atau proses build. Koneksi internet diperlukan untuk memuat font Google; kalkulator tetap dapat digunakan jika font tidak tersedia.

## Pintasan Keyboard

| Tombol             | Aksi                    |
| ------------------ | ----------------------- |
| `0`–`9`            | Masukkan angka          |
| `+`, `-`, `*`, `/` | Operasi matematika      |
| `.`                | Masukkan desimal        |
| `%`                | Persen                  |
| `Enter` atau `=`   | Hitung                  |
| `Backspace`        | Hapus karakter terakhir |
| `Escape`           | Bersihkan kalkulator    |

## Publikasikan dengan GitHub Pages

1. Buka **Settings** pada repositori GitHub.
2. Pilih **Pages** pada menu samping.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
5. Setelah deployment selesai, URL situs akan muncul pada halaman GitHub Pages.

## Teknologi

- HTML
- CSS
- JavaScript (tanpa library eksternal)
